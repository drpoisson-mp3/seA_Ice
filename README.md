# seA_Ice
## Sea Ice Motion from a Machine Learning perspective

### Folders
- Data contains the data as one expects
- Exploration contains many files, more or less chaotically structured where I explored different Neural Nets, training, etc. 
- The monthly folders correspond to the work done that month (might be changed for another structure in the future). Now in the future, I kept the structure but did not do a good job at putting the new files in the new folders. Mostly because, I kept working on the same code from a month to another so I would not move the file. 
- OnetimeTrain contains training python code that can be run once to get a particular set of inputs trained rapidly
- Analysis contains file for the Analysis
- src is a src setup like a pip install packages (to maybe be published in the future) from where I call, functions (dataloading, redimensionalizing, etc.), the models, and some plotting functions

### General Files
- This readme
- environement.yml contains all the Python packages I use in the following code that can be installed via conda (thinking of switching to uv)
- requirements-pip.txt contains the packages that must be install via pip (torch)
- Journal is an attempt at writing down my daily work. Future me here, I did not keep that one going for very long, but my git log captures a lot of the project.
